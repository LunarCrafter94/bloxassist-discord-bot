# Historical documentation and scripts

These files are retained for reference, not as the current operating instructions. For current setup and updates, use the root `README.md` and `INSTALL.md`. For consolidated feature history, use the root `CHANGELOG.md`.

- `releases/`: historical phase/update install notes and changelogs. Some instructions refer to older commands, paths, and permission behavior. Do not follow them to install the current version.
- `original-reference-docs/`: snapshots of the original architecture, naming, owner-requirements, and transaction-safety notes; the maintained versions are directly under `docs/`.
- `tools/history/legacy-release-scripts/`: old version-specific backup and verification scripts. They are archived for audit/history only. Do not run them for routine backups; use `tools/Backup-Project.ps1` and `tools/Test-Project.ps1`.

Historical scripts and notes are kept so their development record is not lost. They are not evidence that every listed behavior remains current.
